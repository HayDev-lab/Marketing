   220→   220→======================================================================
   221→   221→
   222→   222→Создай единый AIProviderRegistry.
   223→   223→
   224→   224→Capability types:
   225→   225→

   238→   238→TRANSCRIPTION
   239→   239→TRANSLATION
   240→   240→EMBEDDINGS
   241→   241→MODERATION
   242→   242→
   243→   243→Каждый adapter должен реализовывать единый contract:
   244→   244→
   245→   245→interface ProviderAdapter {
   246→   246→  providerId: string;
   247→   247→  capabilities: Capability[];
   248→   248→
   249→   249→  validateConfig(): Promise<ValidationResult>;
   250→   250→  healthCheck(): Promise<HealthResult>;
   251→   251→
   252→   252→  estimateCost?(request: unknown): Promise<CostEstimate>;
   253→   253→
   254→   254→  submit(request: unknown): Promise<ProviderJob>;
   255→   255→  getStatus(jobId: string): Promise<ProviderJobStatus>;
   256→   256→  getResult(jobId: string): Promise<ProviderResult>;
   257→   257→
   258→   258→  cancel?(jobId: string): Promise<void>;
   259→   259→}
   260→   260→
   261→   261→Provider Registry хранит:
   262→   262→- provider;
   263→   263→- model;
   264→   264→- capability;
   265→   265→- API status;
   266→   266→- supported languages;
   267→   267→- supported durations;
   268→   268→- reference-image support;
   269→   269→- continuation support;
   270→   270→- aspect ratios;
   271→   271→- max input/output limits;
   272→   272→- estimated cost;
   273→   273→- timeout;
   274→   274→- retry policy;
   275→   275→- fallback order;
   276→   276→- provider-specific constraints.
   277→   277→
   278→   278→Перед реализацией конкретного adapter:
   279→   279→1) открыть актуальную официальную документацию API;
   280→   280→2) проверить model ID;
   281→   281→3) проверить endpoint;
   282→   282→4) проверить auth;
   283→   283→5) проверить async job mechanics;
   284→   284→6) проверить webhook/polling;
   285→   285→7) проверить rate limits;
   286→   286→8) проверить supported media inputs;
   287→   287→9) проверить supported languages;
   288→   288→10) проверить pricing;
   289→   289→11) проверить коммерческие условия;
   290→   290→12) только после этого включать adapter.
   291→   291→
   292→   292→Никогда не предполагать capability по названию модели.

   889→   889→
   890→   890→Resume:
   891→   891→начать со scene_3.

   893→   893→НЕ пересоздавать scene_1 и scene_2.
