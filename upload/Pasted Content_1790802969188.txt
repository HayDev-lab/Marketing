PLAN
→ IMPLEMENT
→ TYPECHECK
→ LINT
→ UNIT TEST
→ INTEGRATION TEST
→ UI TEST
→ MANUAL LOGIC REVIEW
→ SECURITY REVIEW
→ FIND DEFECTS
→ FIX
→ RETEST
→ REGRESSION TEST
→ COMMIT/CHECKPOINT
→ NEXT PHASE

Пока обнаружена ошибка:

DO NOT ADVANCE.

Повторяй:

DETECT
→ ROOT CAUSE
→ FIX
→ VERIFY
→ REGRESSION

до PASS.

Не называй этап завершённым, если:

- тесты не запускались;
- API фактически не проверен;
- UI-кнопка существует, но backend отсутствует;
- используются mocks вместо production implementation;
- ошибка подавлена catch-блоком;
- состояние теряется после reload;
- job невозможно восстановить;
- есть race condition;
- ошибка провайдера отображается как success.
