   219→5. PROVIDER REGISTRY
   220→======================================================================
   221→
   222→Создай единый AIProviderRegistry.
   223→
   224→Capability types:
   225→
   226→LLM
   227→WEB_RESEARCH
   228→IMAGE_GENERATION
   229→IMAGE_EDIT
   230→VIDEO_GENERATION
   231→VIDEO_CONTINUATION
   232→VIDEO_IMAGE_TO_VIDEO
   233→TTS
   234→VOICE_CLONING
   235→VOICE_CONVERSION
   236→MUSIC_GENERATION
   237→AVATAR_VIDEO
   238→TRANSCRIPTION
   239→TRANSLATION
   240→EMBEDDINGS
   241→MODERATION
   242→
   243→Каждый adapter должен реализовывать единый contract:
   244→
   245→interface ProviderAdapter {
   246→  providerId: string;
   247→  capabilities: Capability[];
   248→
   249→  validateConfig(): Promise<ValidationResult>;
   250→  healthCheck(): Promise<HealthResult>;
   251→
   252→  estimateCost?(request: unknown): Promise<CostEstimate>;
   253→
   254→  submit(request: unknown): Promise<ProviderJob>;
   255→  getStatus(jobId: string): Promise<ProviderJobStatus>;
   256→  getResult(jobId: string): Promise<ProviderResult>;
   257→
   258→  cancel?(jobId: string): Promise<void>;
   259→}
   260→
   261→Provider Registry хранит:
   262→- provider;
   263→- model;
   264→- capability;
   265→- API status;
   266→- supported languages;
   267→- supported durations;
   268→- reference-image support;
   269→- continuation support;
   270→- aspect ratios;
   271→- max input/output limits;
   272→- estimated cost;
   273→- timeout;
   274→- retry policy;
   275→- fallback order;
   276→- provider-specific constraints.
   277→
   278→Перед реализацией конкретного adapter:
   279→1) открыть актуальную официальную документацию API;
   280→2) проверить model ID;
   281→3) проверить endpoint;
   282→4) проверить auth;
   283→5) проверить async job mechanics;
   284→6) проверить webhook/polling;
   285→7) проверить rate limits;
   286→8) проверить supported media inputs;
   287→9) проверить supported languages;
   288→10) проверить pricing;
   289→11) проверить коммерческие условия;
   290→12) только после этого включать adapter.
   291→
   292→Никогда не предполагать capability по названию модели.

   753→4. использовать его как next-scene reference, если API модели это поддерживает;
   754→5. передать Character Bible;
   755→6. передать Style Bible;
   756→7. сгенерировать следующую сцену.
   757→
   758→Не утверждать continuity, если конкретная модель/API это не поддерживает.
   759→
   760→Если модель поддерживает start/end frame:
   761→использовать эту capability.
   762→
   763→Если нет:
   764→использовать semantic continuity через:
   765→- character references;
   766→- style references;
   767→- same wardrobe;
   768→- same environment;
   769→- same camera grammar;
   770→- same color palette.
